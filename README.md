# 🇯🇵 Japan Reiseplan PWA

Eine mobile Progressive Web App zur Reiseplanung durch Japan mit Fokus auf Natur, Berge & Meer. Komplett offlinefähig dank Service Worker – ideal für unterwegs!

## 🌍 Live ansehen
**GitHub Pages URL:** `https://<dein-nutzername>.github.io/japan-reiseplan/`

> Stelle sicher, dass der Pfad korrekt ist und deinem GitHub-Nutzernamen entspricht.

## 📦 Inhalt des Projekts
```
/
├── index.html             # Hauptseite mit interaktiver Karte & Tagesübersicht
├── manifest.json          # App-Metadaten für PWA
├── service-worker.js      # Offline-Cache und App-Shell
└── /icons                 # App-Icons für verschiedene Bildschirmgrößen
    ├── icon-192.png
    └── icon-512.png
```

## 📲 Funktionen
- Optimiert für Mobilgeräte
- "Zum Startbildschirm hinzufügen" (installierbar)
- Interaktive Leaflet-Karte mit Reiseroute
- Tailwind CSS-Design
- Offlinefähig via Service Worker
- Unterkunfts- & Restauranttipps pro Station

## 🚀 Anleitung
1. Repository `japan-reiseplan` auf GitHub erstellen
2. Inhalt aus `japan-reiseplan_PWA_final.zip` hochladen (nicht ZIP selbst!)
3. GitHub Pages aktivieren unter **Settings > Pages**
   - **Branch:** `main`
   - **Ordner:** `/ (root)`
4. Besuche die Live-URL (siehe oben)

## 🧩 PWA-Installation
- Öffne die Seite in deinem Handy-Browser
- Wähle "Zum Startbildschirm hinzufügen"
- Voilà – deine App ist installiert 🎉

## 🛠️ Technologien
- HTML, CSS (Tailwind), JS
- Leaflet.js
- Service Worker API
- Web App Manifest
